# Konum tema entegrasyonu

- İl/ilçe/mahalle seçimi, teslimat adresi, adres filtreleri ve konum araması bu modülün adaylarıdır. Genel iletişim adresi, mağaza kaydı veya harita görseli tek başına Konum eşlemesi değildir. Bölümün anlamını incele; eşleme belirsizse kullanıcıya sor.
- Kaynak hiyerarşisi `cities → towns → districts → neighbourhoods → streets` biçimindedir. `districts` mahalle değildir; aradaki kaynak bölgesidir. Posta kodları beş karakterli metindir.
- `Modules\\Konum\\Services\\KonumFrontendService` kullan. `search(string $entity, array $parents = [], string $search = '', int $limit = 25)` aktif ve silinmemiş kayıtları ad/ID sırasıyla bir Eloquent Collection olarak döndürür. Limit 1–100 aralığına çekilir; ad araması önek aramasıdır. Filtreler `city_id`, `town_id`, `district_id`, `neighbourhood_id` olabilir; yalnız seçilen seviyenin üstleri uygulanır. Koddan entity ve alanları doğrula.
- Modül kapalı, kaldırılmış, tablolar eksik veya import tamamlanmamışsa boş sonuç davranışını koru. Kaynakta üst ilişkileri tutarsız kayıtlar ve bunlara bağlı alt kayıtlar `is_consistent=false` ile korunur; servis bunları seçimlere dahil etmez. `warnings` durumundaki importun yalnız tutarlı kayıtları kullanılabilir. Modül hiç kurulu değilken çekirdek controller'a zorunlu sınıf bağımlılığı ekleme; mevcut isteğe bağlı servis çözümleme örüntüsünü kullan.
- `query()` iç kullanım için sınırlanmamış sorgu döndürür; temada bütün cadde/sokakları yükleme. `search()` ile sınırla ve üst seçime göre sorgula. Bu modül herkese açık HTTP adres API'si sağlamaz; gerekiyorsa ilgili ürün akışının yetki ve hız sınırlarıyla ayrıca tasarla.
- Kimlikler kaynak kimliğidir. Çocuk JSON özetleri ilişkisel sorguların yerine geçmez. Model ilişkileri `townRecords`, `districtRecords`, `neighbourhoodRecords`, `streetRecords` adlarını kullanır; JSON alanlarıyla karıştırma.
- `polygons` kaynak MySQL SRID + WKB baytlarının küçük harfli hex karşılığıdır; şifreleme değildir. `PolygonGeometry::decode(string $hex)` Polygon koordinatlarını ve SRID'yi döndürür. SRID ve koordinat sistemini doğrulamadan haritada kullanma; SQLite üzerinde yerel spatial sorgu desteği varsayma.
